## Contents (含まれるもの)
- `Hello.java`: A simple Java program that outputs "Hello, GitHub!". (「Hello, GitHub!」と出力する簡単な Java プログラムです)
- `.gitignore`: Prevents temporary files generated during compilation from being uploaded. (コンパイル時に生成される一時ファイルのアップロードを防ぎます)

## How to Run (実行方法)
